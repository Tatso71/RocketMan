# Runtime Item Icons

51 original transparent SVG game icons, 64 x 64 vector viewbox. The set extends the repository's faceted vector inventory direction; it was drawn in code, not generated by an image model. No external art dependency or font is embedded.

The editable source is `tools/design/build-item-icons.mjs`; do not edit generated SVGs or `catalog.json` directly. Run `node tools/design/build-item-icons.mjs` to regenerate, or append `--check` to detect stale files.

`scripts/data/item_icon_catalog.gd` resolves runtime item IDs, caches imported textures and provides fixed-size views. Levels and repair states intentionally share an object's silhouette; seeds and foods, water/gas pipes, raw ores and processed components remain distinct. Unknown IDs return no icon instead of a misleading fallback.

These are interface assets. They do not mark undiscovered ore in the world. The future ship encyclopedia can read the `icon` paths already exported by the production map.
