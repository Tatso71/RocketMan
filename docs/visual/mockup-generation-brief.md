# RocketMan Visual Mockup Brief

Date: 2026-05-12
Purpose: Use this file with GPT or image-generation tools to explore visual mockups for RocketMan.

## Project Summary

RocketMan is a 2D side-scrolling exploratory platformer set on an unknown planet. The player inherits an underground scientific base after the death of their grandfather, studies alien animal species, explores external biomes, collects materials, and rebuilds an ancestral rocket before the planet collapses.

The game should feel calm, mysterious, scientific, emotional, and exploratory. It is not a frantic survival game and not a combat-first action game.

## Core Visual Fantasy

The player fantasy is:

> I inherited a buried machine-world and a scientific mystery. I learn how this place works, build trust with alien animals, uncover what my family was doing here, and escape an unstable planet through knowledge rather than force.

Visuals should support:

- curiosity
- inherited memory
- quiet isolation
- scientific discovery
- strange but believable alien ecology
- old machinery slowly returning to life
- a rocket as emotional and mechanical objective

## Game Camera And Format

Create mockups as:

- 2D side-view platformer screenshots
- 16:9 aspect ratio
- readable gameplay composition
- clear foreground, midground, and background layers
- player scale visible against environment
- no cinematic close-ups unless explicitly requested

Target image types:

- in-game screenshot mockup
- environment concept frame
- UI overlay mockup
- character/creature lineup
- key art only as a secondary exploration

## Visual Pillars

### Underground Base

The base is the heart of the game. It should feel like a buried scientific habitat built by ancestors, later repaired and modified by the grandfather.

Keywords:

- underground
- old science habitat
- warm personal traces
- cables, terminals, tubes, hatches
- hand-labeled machines
- dormant systems
- low light with readable silhouettes
- mechanical and emotional at the same time

Avoid:

- generic spaceship corridors
- sterile white sci-fi laboratories
- cyberpunk neon overload
- horror bunker mood
- clutter so dense that gameplay paths disappear

### Exterior Biomes

Exterior regions are alien but legible. The player should feel they are studying an ecosystem, not running through random fantasy scenery.

Keywords:

- strange ecology
- readable traversal paths
- organic hazards
- luminous flora
- unusual geology
- alien animals with environmental functions
- calm danger
- discovery through observation

Avoid:

- pure fantasy forest
- hostile monster world
- overly dark survival atmosphere
- abstract alien shapes with no ecological logic

### Animals

Animals are exploration partners, not combat pets. They should look useful, memorable, and biologically plausible within a stylized alien world.

Each creature should communicate:

- environmental role
- movement style
- temperament
- possible ability
- bond potential with the player

Examples:

- Glowlark: small luminous flying species that helps illuminate dark routes.
- Mossback: sturdy low creature that stabilizes fragile terrain or carries small resources.
- Echofin: sound-sensitive amphibious creature that detects hidden currents or resonance paths.

Avoid:

- aggressive monster designs
- generic cute mascots with no function
- designs that look like ordinary Earth animals with one alien detail pasted on

### Player Character

The protagonist should feel curious, intelligent, emotionally affected, and practical. They are not a superhero and not a silent blank avatar.

Visual traits to explore:

- young adult explorer/scientist
- practical suit or work clothes adapted from the grandfather's base
- backpack or scanner
- small repair tools
- subtle family/inheritance detail
- readable silhouette for side-view gameplay

Avoid:

- military armor
- anime battle protagonist
- generic astronaut with no personality
- oversized weapon focus

### Rocket

The rocket is an inherited object and final macro-objective. It should feel old, repairable, meaningful, and partly mysterious.

Keywords:

- ancestral rocket
- workshop centerpiece
- incomplete subsystem panels
- repaired by collected materials
- emotional monument
- practical machine

Avoid:

- sleek NASA realism only
- pure cartoon toy rocket
- generic sci-fi fighter ship

## Style Directions To Explore

Generate several distinct style tests. Do not lock the project to one style too early.

### Direction A: Painterly Storybook Sci-Fi

Soft hand-painted environments, warm base interiors, mysterious alien biomes, readable platformer shapes, emotionally rich lighting.

Good for:

- emotional tone
- inherited mystery
- approachable adventure

Risk:

- may become too soft or decorative if gameplay readability is ignored

### Direction B: Clean Stylized 2D Animation

Crisp silhouettes, flat-shaded forms, clear color blocking, expressive creatures, strong readability similar to premium animated indie games.

Good for:

- platforming clarity
- character appeal
- production practicality

Risk:

- may feel too light unless the base mystery is preserved

### Direction C: Detailed Scientific Illustration

More naturalistic alien ecosystems, field-guide feeling, detailed materials, believable creature anatomy, layered environments.

Good for:

- creature study
- scientific discovery fantasy
- ecological puzzles

Risk:

- may become visually busy for gameplay

### Direction D: Retro-Futurist Workshop Adventure

Old machinery, analog terminals, chunky buttons, grandfather-built devices, warm lamps, worn metal, mysterious tubes.

Good for:

- base identity
- family inheritance
- memorable rocket workshop

Risk:

- exterior biomes need enough freshness to avoid monotony

## Palette Guidance

Use contrast between base and exterior.

Base:

- warm amber work lights
- oxidized teal machinery
- muted metal
- dusty glass
- soft red warning indicators
- old paper labels and personal objects

Exterior:

- cooler alien atmosphere
- luminous biological accents
- mineral blues, greens, icy whites, deep violets only as accents
- region-specific dominant colors

Avoid one-note palettes. Do not make every mockup only blue/purple, only green, or only orange/brown.

## UI Direction

UI should feel like a base research interface, not a generic RPG menu.

Keywords:

- readable
- compact
- expedition planning
- species codex
- material analysis
- schematic unlocks
- terminal UI
- field notes

UI should support controller use and Steam Deck readability.

Avoid:

- tiny unreadable text
- excessive sci-fi noise
- mobile-game style reward popups
- huge decorative panels that hide the game

## Negative Prompt Guidance

Use these as negative instructions when generating images:

- no first-person view
- no generic spaceship corridor
- no military shooter tone
- no horror gore
- no combat-focused action scene
- no photorealistic AAA concept art if gameplay readability is lost
- no cyberpunk city neon
- no fantasy medieval elements
- no random monsters attacking
- no UI text that explains controls or tutorials
- no cluttered foreground blocking player path

## Evaluation Checklist

When reviewing mockups, score each image on:

- Does it feel like RocketMan, not a generic sci-fi game?
- Is the side-scrolling gameplay space readable?
- Does the base feel emotional and functional?
- Do animals look like exploration partners?
- Is the scientific discovery tone present?
- Could this scale into modular biomes?
- Would the UI be readable on Steam Deck?
- Is the rocket objective visually memorable?
- Does the image avoid combat-first or survival-horror signals?
